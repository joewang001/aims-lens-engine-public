# McKinsey Lens Limits

## Public Lens Notice

This lens is inferred from public sources and private-material distillation. It does not represent an official McKinsey hiring standard.

## Current Limits

- v0.1 synthesis draft only.
- Static validation cases have passed, but no live model scoring run has been completed.
- Private material is included only as aggregate distilled evidence; raw text, copied questions, and private URLs are excluded.
- Interview format can vary by office, role, seniority, geography, and recruiting channel.

## Production Blockers

- Run same-answer cross-lens validation against Amazon, Google, Apple, and Microsoft.
- Run live transcript tests and review unsupported claims.
- Complete human review of `profile.json`, `rubric.md`, and `validation_report.md`.
