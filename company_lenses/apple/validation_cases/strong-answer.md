Status: passed static review.

## Interview Question

APL-Q-001: A feature improves engagement but makes the interface more complex and may reduce accessibility for some users. How would you evaluate whether to ship, redesign, or delay it?

## Candidate Answer

I would not treat engagement lift as enough. I would first define the user task the feature improves and identify which users may be harmed by added complexity. I would test accessibility with VoiceOver and dynamic type, measure task completion and error rate, and review performance on older devices.

If the engagement improvement comes mostly from extra taps or visual friction, I would redesign. If the core value is real, I would prototype a simpler interaction and compare it with the current version. I would involve design, accessibility, engineering, and product, then ship only if we can preserve clarity and trust while improving the task.
