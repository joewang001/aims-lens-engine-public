# Experiment 6 — Routing–Shrinkage Overlap Ablation

**Protocol version:** v0.1.0-pre-specified
**Research-release target:** v1.5
**Frozen base:** `v0.10.0-paper-v1.4` at `a0d89f33aaa7303404a9b26cc7bec5a331a6e82f`
**Status:** protocol and fixtures only; no result-bearing Experiment 6 outputs exist at this stage

## Purpose

Experiment 6 isolates one architectural question raised by review of the frozen v1.4 paper artifact:

> Under controlled K=5 synthetic conditions, how does the current routing mixture change held-out predictive behavior relative to the already-shrunken L0 distribution as local evidence density, within-level shrinkage strength, and broader-context mismatch vary?

The experiment compares:

- **Path A — shrunken L0 only:** company-level Dirichlet shrinkage against the supplied L3 parent distribution, with no subsequent broader-level routing mixture.
- **Path B — current routed distribution:** the same shrunken L0 distribution combined with declared L3 and L5 contextual distributions using the frozen v1.4 routing semantics.

The experiment does **not** prespecify that routing must outperform L0-only. It measures whether, where, and by how much the routing layer introduces additional broader-context influence after within-level shrinkage has already occurred.

This is a controlled synthetic architecture ablation. It is not an external calibration study, an employer-behavior model, or a claim of optimal routing.

## Scope and isolation

Experiment 6 targets the actual v1.4 candidate-side inference components relevant to the routing–shrinkage overlap:

```text
declared L3 parent distribution
        ↓
company-level Dirichlet shrinkage
        ↓
shrunken L0 distribution
        ├──────────────→ Path A: L0 only
        ↓
current L0/L3/L5 routing mixture
        └──────────────→ Path B: routed distribution
```

To isolate this question:

- all five categories are permitted;
- no compatibility masking is applied;
- all routing levels are authorized;
- all routing levels are applicable;
- all routing components retain positive permitted mass;
- evidence records are fresh, fully authorized, and quality 1.0;
- runtime data-support and abstention gates are not part of this ablation.

Later implementation must call the existing public shrinkage and routing functions rather than reimplementing altered experiment-specific semantics.

## K=5 category space

The fixed category order is:

1. `ownership`
2. `evidence`
3. `tradeoff`
4. `collaboration`
5. `reflection`

The base synthetic company truth is:

[
\theta^{(0)}=(0.34,,0.26,,0.18,,0.13,,0.09).
]

Five company-truth variants are generated by cyclic left rotations:

[
\theta^{(r)}=R_r(\theta^{(0)}),\qquad r=0,\ldots,4.
]

This prevents the benchmark from depending on one named category always occupying the dominant position.

## Broader-context mismatch

For each company truth (	heta), broader contextual distributions are deterministic controlled stress conditions:

[
L3(\rho)=(1-\rho)\theta+\rho R_1(\theta),
]

[
L5(\rho)=(1-\rho)\theta+\rho R_2(\theta).
]

The prespecified mismatch levels are:

| Regime | (\rho) |
|---|---:|
| High agreement | 0.10 |
| Moderate mismatch | 0.40 |
| Strong mismatch | 0.80 |

These labels do not represent empirical industry/company divergence. For every condition, the runner must also report the actual total-variation distances (TV(L3,	heta)) and (TV(L5,	heta)).

## Company evidence density

For each training replicate, company observations are independently generated from:

[
Y_c\sim\operatorname{Categorical}(\theta).
]

The local sample-size regimes are:

| Regime | (n_c) |
|---|---:|
| Sparse | 2 |
| Intermediate | 10 |
| Dense | 50 |

Each generated evidence record is declared:

- `authorized = true`;
- `quality = 1.0`;
- `age_days = 0.0`.

Thus authorization, quality, and temporal decay do not confound the routing–shrinkage comparison.

## Within-level shrinkage strength

The company-level parent concentration is prespecified as:

[
\kappa_c\in\{2,6,20\}.
]

For company counts (n_{c,k}), Path A begins from the existing v1.4 company-level shrinkage semantics:

[
q^{L0}_k=
\frac{\kappa_c L3_k+n_{c,k}}
{\kappa_c+n_c}.
]

The three values represent weaker, baseline-like, and stronger parent influence. No value is claimed to be empirically optimal.

## Routing configuration

Experiment 6 retains the frozen v1.4 routing form for L0, L3, and L5:

[
d_{L0}=0,\qquad d_{L3}=3,\qquad d_{L5}=5.
]

The declared coverage inputs are fixed as:

[
c_{L0}=0.78,\qquad c_{L3}=0.92,\qquad c_{L5}=1.00.
]

These are **fixture constants**. They are not empirical coverage estimates, calibrated probabilities, correctness probabilities, or outputs of an EvidencePacket-to-coverage estimator.

Authorization and applicability are both 1 for all three routing levels.

The raw routing score is:

[
r_\ell=a_\ell s_\ell c_\ell \gamma^{d_\ell},
]

and, because every declared component remains eligible and has positive permitted mass in this experiment,

[
\omega_\ell=
\frac{r_\ell}{\sum_m r_m}.
]

## Backoff strength

The prespecified routing discounts are:

[
\gamma\in\{0.4,0.7,0.9\}.
]

With the fixed coverage inputs above, the expected routing weights are:

| (gamma) | L0 | L3 | L5 |
|---:|---:|---:|---:|
| 0.4 | 0.9185980780 | 0.0693423780 | 0.0120595440 |
| 0.7 | 0.6172692956 | 0.2497249986 | 0.1330057058 |
| 0.9 | 0.3821337762 | 0.3285762577 | 0.2892899660 |

The (gamma=0.7) condition must reproduce the frozen paper-example routing weights to the declared numerical tolerance.

## Compared paths

### Path A — Shrunken L0 only

[
q^A=q^{L0}.
]

No broader-level mixture is applied after company-level shrinkage.

### Path B — Current routed distribution

[
q^B=
\omega_0q^{L0}
+\omega_3L3
+\omega_5L5.
]

Path B must use the existing routing implementation. Experiment-specific code must not substitute a different mixture or learned routing rule.

## Factorial design

The primary factorial design is:

- 3 company evidence densities: (n_c\in\{2,10,50\});
- 3 broader-context mismatch levels: (\rho\in\{0.10,0.40,0.80\});
- 3 shrinkage strengths: (kappa_c\in\{2,6,20\});
- 3 routing discounts: (gamma\in\{0.4,0.7,0.9\}).

This gives:

[
3\times3\times3\times3=81
]

primary conditions.

Each condition is evaluated over:

- 5 cyclic rotations of the company truth;
- 100 independent paired training replicates per rotation.

Total paired A/B training realizations:

[
81\times5\times100=40{,}500.
]

For each realization, Path A and Path B use the **same** generated company training sample.

## Held-out observations

For every paired training realization, independently generate:

[
N_{test}=200
]

held-out categorical observations from the same true company distribution:

[
Y_{test}\sim\operatorname{Categorical}(\theta).
]

Total held-out observations across the full design:

[
40{,}500\times200=8.1\text{ million}.
]

The generated held-out records provide synthetic predictive diagnostics. They do not establish real-world or population calibration.

## Deterministic seed contract

The experiment must not rely on Python's process-dependent `hash()`.

Each replicate seed is derived deterministically from SHA-256 over a canonical string containing:

```text
protocol_version
rotation
n_c
rho
kappa_c
gamma
replicate
```

A fixed documented byte slice of that digest is converted to an integer seed. Reordering loops must not change any generated dataset.

## Primary population metrics

Because the true synthetic company distribution (	heta) is known, the primary comparison uses exact population scores in addition to finite held-out samples.

### Exact expected log loss

For a predicted distribution (q):

[
LL(q;\theta)=-\sum_k\theta_k\log q_k.
]

Report the paired delta:

[
\Delta LL=
LL(q^{route};\theta)-LL(q^{L0};\theta).
]

Interpretation:

- (Delta LL<0): routing improves the score;
- (Delta LL=0): no change;
- (Delta LL>0): routing worsens the score.

### Exact expected multiclass Brier score

For one-hot categorical outcomes:

[
BS(q;\theta)
=
1+\sum_k q_k^2-2\sum_k\theta_k q_k.
]

Report:

[
\Delta BS=
BS(q^{route};\theta)-BS(q^{L0};\theta).
]

### Total variation from company truth

[
TV(q,\theta)=\frac12\sum_k|q_k-\theta_k|.
]

Report:

[
\Delta TV_{truth}
=
TV(q^{route},\theta)-TV(q^{L0},\theta).
]

No pass/fail criterion requires any of these deltas to favor routing.

## Direct routing-overlap diagnostics

The experiment must directly report the additional distributional movement introduced after L0 shrinkage:

[
TV_{routing\ shift}=TV(q^{route},q^{L0}).
]

Also report:

- normalized entropy for Path A and Path B;
- whether the top category is retained or changed;
- normalized routing weights;
- (TV(L3,	heta)) and (TV(L5,	heta)).

No new opaque "company-signal retention probability" is introduced.

## Held-out diagnostics

On generated held-out observations, report for both Path A and Path B:

- multiclass Brier score;
- multiclass log loss;
- top-label ECE;
- top-label accuracy as a descriptive diagnostic.

Top-label ECE is secondary only:

- 10 equal-width confidence bins;
- not a proper scoring rule;
- not evidence of external calibration.

To reduce per-replicate bin noise, ECE is pooled within each primary factorial condition across all five rotations, all 100 replicates, and their held-out observations.

## Aggregate reporting

For each of the 81 primary conditions, report paired replicate distributions for at least:

- (Delta LL);
- (Delta BS);
- (Delta TV_{truth});
- (TV_{routing\ shift}).

For the paired deltas, report:

- mean;
- median;
- 5th percentile;
- 95th percentile;
- proportion of replicates for which routing improves the corresponding metric.

The 5th and 95th percentiles are **replicate-distribution percentiles**, not confidence intervals.

## Result interpretation

Experiment 6 may report that routing improves, has negligible effect, or worsens predictive behavior in different synthetic regimes. Negative findings must not be suppressed.

The protocol does not authorize statements that routing is globally optimal, statistically necessary, or non-redundant. It only quantifies the additional influence introduced by routing under the declared controlled conditions.
